## PM Concept of the Day: Total Float vs. Free Float

Float (slack) is how long an activity can slip without causing a problem. *Total float* is the delay allowed before the project end date moves (late start − early start); *free float* is the delay allowed before the very next activity's early start is pushed. Critical-path activities have zero total float, and a path with negative float is already behind. In fintech delivery, say a KYC-vendor integration has 6 days of total float but 0 free float because the sandbox-testing task starts right after it: a slip there doesn't threaten go-live, but it immediately delays testing and eats the shared float of every other task on that path. For the exam, remember that float is path-wide, so one task using it up reduces what the others have.

## One Thing to Try Today (10 minutes)

Sketch a 6–8 task schedule for something familiar, such as a small feature release. Give each task a duration and its predecessors. Do a forward and backward pass by hand to find the critical path, then write down the total float of each non-critical task. Pick one with float and note what could realistically use it up.
